# Bubble Royale Homepage

Responsive premium homepage for Bubble Royale. `index.html` is now fully self-contained: the CSS, JavaScript and all supplied transparent PNG assets are embedded directly in the file, so it also works when opened from an Android `content://` download link.

`index-modular.html`, `styles.css`, `app.js` and `assets/` remain available for normal web-server deployment and future maintenance.

No external libraries or newly generated images are required.
